# Joshua Bullecer Portfolio — Netlify Package

## Deploy to Netlify
1. Log in to Netlify.
2. Open **Sites**.
3. Choose **Add new site** > **Deploy manually**.
4. Drag the extracted folder into the upload area.

No build command is required.

## Files
- `index.html` — main portfolio page
- `styles.css` — styling
- `netlify.toml` — Netlify configuration
- `_redirects` — fallback routing

## Before publishing
Update the contact button in `index.html`:
`href="mailto:"`

Replace it with your preferred email address, e.g.:
`href="mailto:yourname@email.com"`
